# 验证说明

此仓库保存 FlClash Pilot v1.1，针对 FlClash v0.9.1 设计。

## 可复现的本地验证

在 Windows 中运行 `build.ps1 -Test`，重新编译程序和测试。测试使用虚拟数据及本机随机端口的模拟接口，不访问真实代理控制器，不读取用户订阅。

- Windows 逻辑：本机地址限制、滚动样本、失败比例、连续领先、切换冷却、轮测覆盖、嵌套组基准与恢复，以及修改连接参数后丢弃旧连接。
- 模拟接口：中文及特殊字符 URL 编码、鉴权失败、超时、读回核验、流量统计及取消操作。只出现一次预期的模拟 PUT，不修改规则、DNS 或订阅。
- 安卓脚本：输入不被原地修改，原节点、规则及 DNS 保留，排除直连、空组拒绝、重复执行一致、命名冲突、代理集合健康检查及过滤条件保留。
- 生产源码以不请求管理员权限的清单编译；仓库内 EXE 的 SHA-256 见 `SHA256SUMS.txt`。

## 实机边界

- 旧版曾完成真实控制接口连接与只检测操作，但这不能证明 v1.1 的真实自动托管与恢复已经通过。
- 尚未在真实安卓手机导入和执行脚本，也未使用个人配置完成 mihomo 内核校验。
- 本地模拟不替代真实 GUI 接管、后台运行或切换效果验证。
- 没有使用真实下载带宽证明提速，延迟较低不等于带宽最大。
- 同名节点的服务器或凭证变化可能无法识别；更新订阅、切换配置前应暂停，完成后重新连接。
